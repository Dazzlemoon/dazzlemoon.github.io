Hey，我是邱祺智（qqz）：白天假装在搞固态电池 / MLIP / 谱学，晚上是摸鱼爱好者兼学术讨口子—— 每天会更新那些「别人读完了、我还没打开 PDF」的文献。

我这个人，计划写得比实验还漂亮，执行起来比 Li⁺ 在坏界面上还慢。于是建了这座博客：一方面逼自己看文章，另一方面欢迎大家来监督我——欢迎大家评论或加我的QQ（2393474010）与我交流~

这是用 GitHub Pages 和 Jekyll 搭的个人站点，代码在 GitHub · qqz。一般在公众号也会同步更新；这里当备份 + 检索友好版，免得哪天微信又「该内容无法查看」。
